## Overview

AIR Vacuum models the harmonic distortion characteristics of classic triode vacuum tubes, adding controllable even-order harmonics, output level, and tone shaping for warm analog saturation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **AIR Vacuum** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Triode Model** | Even-harmonic saturation characteristic of classic 12AX7 triode stages |
| **Drive Control** | Input drive from subtle warmth to heavy tube overdrive |
| **Tone Shaping** | High-frequency rolloff and presence controls for output color |
| **Wet/Dry Mix** | Parallel wet-dry blend for transparent harmonic addition |
